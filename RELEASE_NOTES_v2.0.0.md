# v2.0.0 — Null transport, lumpability, and SINCA PM2.5 application

This is a major methodological and applied revision of the reproducibility package.

## Main changes

- Reframed the inferential problem as null transport under temporal coarse-graining.
- Added strong lumpability and quotient-null formalism.
- Added an analytical counterexample showing failure of lumpability under marginal-preserving spectral conditioning.
- Added Gaussian oracle and operator-ablation diagnostics.
- Added the near-zero soft-to-hard threshold analysis.
- Added within-fiber numerical evidence against strong lumpability of the implemented native surrogate contract.
- Added a prospectively frozen application to 31 Chilean SINCA PM2.5 monitoring stations.
- Added fixed-threshold, probability-equalization, and missingness-sensitivity analyses.
- Added executable Python scripts and station-level outputs for the SINCA application.
- Replaced the former Amazon-CMIP6 illustration in the manuscript.
- Updated the manuscript, Supplementary Material, figures, references, and reproducibility documentation.
- Retained the original confirmatory synthetic evidence.

The SINCA station cohort and inferential protocol were frozen before application-level surrogate results were inspected.
