# v1.1.0 — SERRA submission metadata release

This release aligns the reproducibility package with the manuscript submitted to **Stochastic Environmental Research and Risk Assessment (SERRA)** under the title:

*Surrogate inference for threshold-derived environmental indices depends on null placement and seasonal event concentration*.

## What changed

- manuscript-facing title and repository description;
- citation and Zenodo metadata;
- environmental/hydroclimatic terminology used to describe the archived analysis;
- release documentation clarifying the interpretation of the CMIP6 Amazon case study.

## What did not change

No confirmatory experiment was rerun or tuned for this release. The prespecified Stage 3, Stage 4, Stage 5, and Stage 5C protocols, frozen hashes, analysis scripts, row-level outputs, figure source data, and headline numerical results are unchanged from v1.0.0.

The earlier immutable archive remains available as v1.0.0 at DOI `10.5281/zenodo.21873328`.
